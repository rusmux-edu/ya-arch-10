# Проблемные зоны безопасности данных

| **Проблема**                                                             | **Описание**                                                                                                 | **Риски**                                            | **Нарушение нормативных требований**         |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | -------------------------------------------- |
| Небезопасное хранение конфиденциальных данных в файлах (Excel, JPG, PDF) | Персональные данные клиентов сохраняются в незашифрованном формате                                           | Угроза взлома, утечка информации, повреждение данных | Несоответствие закону 152-ФЗ                 |
| Доступ к конфиденциальным данным через общий сетевой диск                | Файлы с персональными данными размещены в общей сетевой папке без контроля доступа и журналирования операций | Неавторизованный доступ, утечка данных               | Нарушение 152-ФЗ                             |
| Отсутствие системы резервирования данных                                 | Не настроено автоматическое создание резервных копий                                                         | Риск безвозвратной потери информации                 | Невыполнение требований 152-ФЗ к хранению ПД |
| Использование неподготовленных серверов в офисных помещениях             | Локальные серверы размещены в офисе без должной защиты от физического доступа и сбоев электропитания         | Возможность хищения оборудования, повреждение данных | Нарушение 152-ФЗ                             |
| Отсутствие ролевой модели доступа и мониторинга действий                 | Все сотрудники имеют полный доступ к общим файлам без ограничений                                            | Несанкционированное использование данных             | Несоответствие 152-ФЗ                        |
| Децентрализованное управление доступом к информации                      | Нет единой системы контроля прав доступа к данным                                                            | Трудности в управлении правами при росте компании    | Нарушение 152-ФЗ                             |
| Нет журналирования действий пользователей                                | Отсутствует запись операций, выполняемых с данными                                                           | Невозможность расследования инцидентов               | Несоответствие 152-ФЗ                        |
| Передача данных без защиты                                               | Информация отправляется между сотрудниками в открытом виде                                                   | Перехват данных злоумышленниками                     | Нарушение 152-ФЗ                             |
| Небезопасное взаимодействие с внешними сервисами                         | Данные передаются в лаборатории и сторонние системы без использования защищенных протоколов                  | Угроза утечки информации при передаче                | Несоответствие 152-ФЗ                        |
| Нет проверки целостности данных                                          | Отсутствуют механизмы контроля неизменности данных при передаче                                              | Риск подмены или искажения информации                | Нарушение 149-ФЗ                             |
| Недостаточная подготовка сотрудников                                     | Персонал не обучен правилам обработки конфиденциальных данных                                                | Случайные нарушения политик безопасности             | Несоответствие 152-ФЗ                        |
| Нет регламента реагирования на угрозы                                    | Не определены процедуры действий при возникновении инцидентов информационной безопасности                    | Задержки в устранении угроз                          | Нарушение 152-ФЗ                             |
| Отсутствие регулярных проверок защиты данных                             | Не проводятся плановые аудиты состояния информационной безопасности                                          | Неконтролируемое накопление уязвимостей              | Несоответствие 152-ФЗ                        |
