# Классификация данных

Данные компании делятся на конфиденциальные (PII, PHI) и неконфиденциальные

|        **Данные**         | **В чем необходимость защиты**                                                            | **Инструменты защиты**                                               |
| :-----------------------: | :---------------------------------------------------------------------------------------- | :------------------------------------------------------------------- |
| Персональные данные (PII) | Cоответствие ФЗ-152 и/или GDPR                                                            | шифрование (AES-256), транспорт через защищенные каналы (HTTPS, VPN) |
| Медицинские данные (PHI)  | Защита врачебной тайны (ст. 13 ФЗ-323). Риск: судебные иски, штрафы, репутационные потери | шифрование (AES-256), транспорт через защищенные каналы (HTTPS, VPN) |
|     Финансовые данные     | Соответствие PCI DSS                                                                      | TLS                                                                  |

## Инструменты защиты и автоматизированный контроль

- включить автоматическое шифрование данных
- настроить защищенные каналы связи внутри организации
- реализация контроля доступа (Keycloak RBAC)
- сканирование данных для обнаружения PII/PHI (Symantec)
- MFA (OAuth 2.0 / OpenID )
- вести access log для отслеживания обращений к данным
- можно попробовать внедрить Apache NiFi для реализации Data Lineage, он поддерживает шифрование, контроль доступа и отслеживание происхождения данны
